# Learning C++

Small exercises from when I first started learning C++ (August 2026). Each folder is a single-file program.

| Program | What it practises |
|---------|-------------------|
| [count-to-ten](count-to-ten/count_to_ten.cpp) | `while` loops: prints the numbers 1 to 10 |
| [multiply-by-two](multiply-by-two/multiply_by_two.cpp) | Input and output: reads an integer and prints it doubled |
| [is-equal](is-equal/is_equal.cpp) | Functions and `bool`: checks whether two integers are equal |
| [brainrot-number](brainrot-number/brainrot_number.cpp) | `if` / `else if` / `else`: tells you how far your number is from 67 |

To run one, compile it with any C++ compiler, for example:

```
g++ count-to-ten/count_to_ten.cpp -o count_to_ten
./count_to_ten
```
